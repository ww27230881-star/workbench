# ⚡ 效率工作台（单文件 HTML）

一个完全离线、不需要联网/安装/登录的效率工具。双击 `index.html` 就能用。

## 功能模块

| 模块 | 作用 |
|---|---|
| 🏠 总览 | 今日待办完成率、今日支出、习惯打卡、本周学习、存钱进度、接下来 2 小时的提醒 |
| ✅ 待办清单 | 按日期安排任务，优先级/分类/时间，逾期标红 |
| 📅 日 / 周计划 | 日计划 = 时间块安排；周计划 = 7 天网格 + 本周目标 |
| 💸 记账 | 支出/收入、分类、月度统计 + 分类占比 |
| 🔥 习惯养成 | 按频率分组（每天/每周）+ 28 天打卡格子 + 连续天数 + 周进度条 |
| 🍅 学习计划 | 科目每周目标小时数 + 手动记录 + 番茄钟（专注 25 / 休息 5） |
| ⏰ 提醒 | 一次 / 每天 / 间隔三种；一键添加「放下手机」等预设 |
| ⚙️ 设置 / 备份 | 通知开关、响铃、深色模式、导出 / 导入 JSON 备份 |

## 提醒要生效，必须满足 3 个条件

1. 用 **Chrome 或 Edge** 打开本页（不是微信/QQ 内置浏览器）
2. 点一次「🔔 开启桌面通知」并允许
3. **页面保持开着**（可以最小化，不能关掉标签页）

到点会弹系统通知 + 响铃。页面关着就收不到——这是浏览器限制。

## 数据

- 所有数据存在**本机浏览器**里（localStorage），不会上传到任何服务器
- 换电脑/换浏览器：设置页「导出备份」→ 新设备「导入备份」
- 建议每周导出一次，防止误清浏览器数据

## 🛰️ 云同步（手机 / 平板 / 电脑共用一份数据）

部署到网上的版本（GitHub Pages 永久链接）支持云同步：

1. **获取 Token**（一次性）：打开 `github.com/settings/tokens` → Generate new token (classic) → 勾选 `gist` 权限 → Generate → 复制（`ghp_` 开头）
2. **每台设备**：打开同一个网页 → ⚙️ 设置 → 云同步 → 粘贴同一个 Token → 「连接并同步」
3. 之后任意设备上的修改，其他设备打开页面（或点「立即同步」）就能看到

规则：
- 以「最后修改的设备」为准；本地数据被云端覆盖前会自动备份（可在设置里「恢复自动备份」）
- Token 只保存在各设备浏览器本地，不进网页代码；**请勿外传**（泄露就去 GitHub 撤销重发）
- 同步数据存在你自己的**私有 Gist** 里，随时可以在 github.com/gists 看到

## 手机用

把 `index.html` 传到手机（微信文件传输助手 / 网盘），用手机 Chrome 打开，添加到主屏幕，效果接近 App。提醒同样需要页面开着。

## 说明

- 番茄钟完成一轮自动把专注分钟数计入所选科目
- 「放下手机」间隔提醒默认每 30 分钟响一次，可在提醒列表里删掉或改
- 首次使用所有内容为空，全部手动添加，AI 不会帮你填任何数据
